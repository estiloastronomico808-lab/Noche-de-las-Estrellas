# Noche de las Estrellas 2026 – Sedes (PWA)

Página instalable (PWA) para encontrar la sede más cercana de la Noche de las Estrellas 2026.

Archivos: `index.html` (página y datos), `sw.js` (modo sin internet), `manifest.webmanifest` (datos de la app),
`Banner.png` (banner superior) e íconos (`icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png`).
